list of high-level prompt examples, grouped by category. These are the kinds of jobs the OS can automate when it can:

• read files and folders,

• launch apps,

• access the browser,

• manipulate documents,

• run shell commands,

• trigger coding assistants like Cursor / Claude Code / Copilot / Codex,

• interact with email, calendar, chat, Git, and local systems.

16. Good “agent-level” task classes to support

• Simple workflow task: one app, one action, one outcome

• Multi-step workflow task: cross-app orchestration

• Research task: gather, summarize, structure, and report

• Creative task: write email, doc, design copy, summaries

• Coding task: implement features, tests, fixes

• Administration task: package install, config, tuning, backups

• Security task: monitor, contain, and report

• Compliance task: audit, summarize, export

• Browser task: interact with web apps and forms

• GUI task: click, edit, navigate within the desktop

17. The most valuable prompt classes for your projectThese are the ones that make the OS feel “agentic”:

• “Open the relevant app, do the necessary workflow, and report completion.”

• “Find the data, operate on it, and save the result in the expected format.”

• “Take the task from intent to execution across apps without me needing to click around.”

• “Act on my behalf within the OS in a way that is auditable and safe.”

• “Use the right app/tool for the job, not just a shell command.”
